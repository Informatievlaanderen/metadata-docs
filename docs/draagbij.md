# metadata-docs

Deze documentatie wordt opgebouwd via een GitHub repository die automatisch op GitHub Pages wordt gepubliceerd na merge in de `main` branch. De paginas worden beschreven in [Markdown](https://www.markdownguide.org/) en met [Zensical](https://zensical.org/) omgebouwd tot een statische webpagina.

In de file [hidden/examples.md](hidden/examples) kan je Markdown syntax terugvinden die in gebruik is op deze pagina's, zodat je gemakkelijk van start kan gaan op basis van voorbeelden.
